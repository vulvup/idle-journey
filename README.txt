# 異界旅人：Idle Journey v0.1

這是第一版跨平台 PWA 原型，支援 Android 與 iPhone 的現代瀏覽器。

## 如何測試
1. 將整個資料夾放到支援 HTTPS 的靜態網站主機（例如 GitHub Pages、Netlify）。
2. 用手機 Safari（iPhone）或 Chrome（Android）開啟網站。
3. iPhone：分享 -> 加入主畫面。
4. Android：瀏覽器選單 -> 安裝應用程式 / 加到主畫面。

注意：PWA 安裝通常需要 HTTPS（localhost 開發例外）。直接點開電腦上的 HTML 檔可以預覽，但不能完整測試安裝與離線快取。

## v0.1 已有功能
- 單人動漫風冒險者主畫面
- 每 5 秒自動探索並獲得金幣、經驗
- 升級與攻擊力強化
- 最多 8 小時離線收益（重新開啟時計算）
- 本機瀏覽器存檔
- 基本離線快取

## 目前限制
- 尚未接入雲端存檔；清除瀏覽器資料可能導致進度遺失。
- 尚未實作真正的動態桌布、推播、背景常駐執行。
- 遊戲數值和畫面仍是原型，可在下一版擴充角色、怪物、裝備和地圖。
